arctictab

Flexible tab grouping and fast search using local embedding model.

Pinned tabs are kept where they are and never join a group.

Tab search

A search box at the top of the sidebar for jumping to an open tab. Ranks matches with the on-device embedding model blended with keyword (BM25) matching. The keyboard shortcut below opens the same search as a toolbar panel, whether or not this box is shown.

Suggestions: Ctrl+Shift+F, Ctrl+Shift+Space, or Alt+Shift+T. Combine modifiers (Ctrl, Alt, Shift) with a letter or key.

The toolbar button opens this same search panel. Its "Sidebar" button opens the arctictab sidebar.

Close group

Closes every tab in the group the current tab belongs to. Does nothing when the current tab is not in a group. If that group is all the window holds, the window closes with it.

Pinning

Show pin buttons on tabs and groups. Pinned groups have a frozen name and a fixed set of member tabs; reclustering won't move pinned tabs out.

Show the bookmark ★ button on each group (bookmarks all tabs in a group to the Bookmarks Toolbar).

Tabs sharing a URL or a title are always placed in the same group, however many there are. They are also left out of the group-size math entirely, so a pile of identical tabs (a stack of new tabs, say) cannot skew "Control group size" or its penalties for everything else.

Keep identical tabs in a group of their own rather than letting them join the group they most resemble. When off, other tabs can end up alongside them.

When "Re-organize tabs" runs, also reorder the groups themselves by content similarity (greedy nearest-neighbor on group centroids), so related groups end up adjacent in the tab strip. When off, groups stay in their current left-to-right order.

Moves tabs. Clusters by content across the whole tab strip rather than by position, then rearranges the strip and creates Firefox tab groups automatically every time the clustering recomputes. Matching pages end up together no matter where they were opened. When off, tabs are never moved on their own and groups follow the existing strip order. While on, the sidebar's "Re-organize tabs" button is hidden, since pressing it would only repeat what already happens on every recompute.

When unchecked, group names don't auto-update and newly opened tabs appear below a separator until you click "Apply groups".

Adds the ⧉ button to the sidebar, which copies the current tabs, clusters and settings to the clipboard as JSON. Useful for reporting a bad grouping.

Diagnostics

Off by default. When on, verbose messages are written to the browser console and the ⎘ button (copies the session log and a snapshot to the clipboard) appears in the sidebar. Leave off unless you're diagnosing an issue.
